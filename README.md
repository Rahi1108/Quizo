# Quizo
A web based quiz game specially designed for students.
Quizo is a fun and responsive quiz application built with HTML, CSS, and JavaScript.
It was designed as a team project to practice DOM manipulation, event handling, and dynamic UI updates without using any frameworks.

✨ Features

Dynamic Question Rendering – Questions and options are loaded from a JavaScript array, not hardcoded in HTML.
Multiple Choice Support – Each question has 4 answer options with only one correct answer.
Answer Tracking – Selected answers are saved, so users can navigate back and see their choices.
Navigation Controls – "Next" and "Previous" buttons to move between questions.
Score Calculation – Displays total score and correct answers at the end.
Responsive Design – Works smoothly on desktop, tablet, and mobile screens.
Prevent Skipping – Users must select an answer before moving to the next question.

🛠 Tech Stack

HTML5 – Structure & layout
CSS3 – Styling & responsiveness
JavaScript (Vanilla) – Core quiz logic, DOM updates, and user interaction handling
